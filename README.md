# Mini NPU Simulator (MAC 연산 기반 패턴 판별 계산기)

AI 하드웨어(NPU)의 핵심 연산인 **MAC(Multiply-Accumulate)** 원리를 순수 Python 반복문으로 구현하고, `3×3`부터 `25×25`까지 다양한 크기의 2차원 패턴(`Cross`, `X`)을 판별하며 연산 성능과 부동소수점 오차 영향을 분석하는 콘솔 애플리케이션입니다.

---

## 1. 실행 방법

### 실행 환경 및 파일 구성
- **Python 버전**: Python 3.8 이상 (외부 라이브러리 미사용, 표준 라이브러리 `json`, `time`만 사용)
- **파일 위치**:
  - `main.py`: 메인 실행 파일
  - `data.json`: `5×5`, `13×13`, `25×25` 크기별 필터(`filters`) 및 테스트 패턴(`patterns`) 데이터 (`main.py`와 동일 디렉토리에 위치)

### 프로그램 실행 및 모드 선택
터미널에서 아래 명령어를 입력하여 시뮬레이터를 실행합니다.

```bash
python3 main.py
